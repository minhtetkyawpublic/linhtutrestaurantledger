# Bundled Myanmar PDF font

`Padauk-Pdf.ttf` is bundled so generated receipts and customer statements
can render Myanmar Unicode text without relying on fonts installed on the web
server.

The PDF font is a build-time subset of `Padauk-Regular.ttf` containing Latin,
Myanmar (`U+1000–U+109F`), and general punctuation. The source font is retained
for reproducibility.
